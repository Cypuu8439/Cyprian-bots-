Questions

Frequently asked

Does this site verify payment?

No. It links to the existing payment page; automatic verification needs a secure backend.

Will this form deploy my bot?

No. It is a front-end starter. Form processing, admin access and notifications need a backend.

Should I share my session string?

Only with a service you trust. Treat it like a password and never publish it on GitHub.

Who deploys the bot?

The intended workflow is manual deployment by the admin after review.
