- Mobile-friendly landing page and request-form interface

## Important
This is a static GitHub Pages site. The request form only validates in the browser; it does NOT send or save information. Do not submit WhatsApp session strings here. Session strings are sensitive account-access credentials.

Automatic payment verification, secure session collection/storage, admin dashboard and WhatsApp notifications require a secure backend and database. This ZIP does not claim those features are live.

## Publish from Android
1. Download and extract the ZIP.
2. In GitHub, create a repository named `cyprian-bot-hosting-pages`.
3. Upload `index.html` to the repository root.
4. Open repository **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish the site.

Never upload `.env` files, passwords, API keys, session strings or customer data to GitHub.
